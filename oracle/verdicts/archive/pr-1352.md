## Stage 2 — Quality Review

**Leading newline (engineer-flagged):** Not a regression. On `main`, the f-string begins `f"""\n:root {{`. The PR changes this to `f"""\n{css_version_comment}\n:root {{`. The pre-existing leading newline was already in the output; the PR adds one line between it and `:root {`. Inside an HTML `<style>` block, whitespace before `:root {` is inert to all CSS parsers.

**Fallback `"?"` (engineer-flagged):** The fallback is structurally unreachable via the standard call chain. `load_conventions()` calls `_validate()`, which requires `conventions_version` to be present or raises `ValueError`. Any caller that gets a `conventions` dict from `load_conventions()` will always have `conventions_version` populated. The fallback only fires if someone hand-constructs a `dict` without the key and passes it directly to `_build_global_css()`. The 5 new `TestCssVersioning` unit tests all call `load_conventions()` first, so they test the normal path but not the fallback path. This is a known gap but not a blocker given the validation contract upstream.

**Test coverage:** 8 new tests. Three at the integration level (`TestRender`): presence of the pattern, exact version match, positional assertion (comment precedes `:root {` within 120 chars). Five at the unit level (`TestCssVersioning`): presence, version match, position, regression-guard (color tokens unchanged), and a concrete version assertion (`v1.0`). The concrete version assertion (`test_build_global_css_version_is_v1_point_0`) will require updating when `conventions_version` is bumped — this is acceptable and the test name is clear about its specificity.

**Pattern check (test_build_global_css_version_is_v1_point_0):** This test hardcodes the string `"/* lobster-html-primitives v1.0 */"` directly. It does not import a constant from `conventions.py`. This is a minor mirror-constant risk (learnings.md, PRs #696, #800, #967 etc.) — but at low severity. The test is self-documenting (the name says `v1_point_0`) and the production value is a YAML string, not a Python constant. The test will fail loudly when the version bumps, which is the intended behavior. Not a blocker.

**Encoded Orientation check:** No. This PR modifies a CSS generation function to prepend a comment. It does not change behavioral defaults, system constraints, agent identity, or decision-making rules.

**56 tests pass.** No failures.
